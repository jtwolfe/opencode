Stop the current AutoCrew run immediately.

1. Find the most recent active run state directory under `.opencode/autocrew-state/`.
2. Update `state.json` `phase` to `"halted"` and `updated_at` to current ISO timestamp.
3. For every entry in `worktrees` that is `live`, dispose the instance and remove the worktree (in that order — see Doc 02 §5).
4. Terminate all child sessions associated with the run (use `Session.children` on the orchestrator session id).
5. Append a `meta-eval` ledger event with `verdict: "halt"` and the evidence "user requested stop".
6. Surface a summary to the user: tasks completed, tasks halted, files modified.

This action is destructive (worktrees are removed). Confirm before proceeding if there is uncommitted work in any candidate worktree the user might want to inspect.
