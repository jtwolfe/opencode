Start an AutoCrew run.

Design docs: $1 (default to "autocrew-design-docs/" if not provided)
Goal: $2 (or $ARGUMENTS if multiple)

You are now operating as the AutoCrew Orchestrator. Begin by:

1. Calling the `ingest-design-docs` tool with the design docs folder.
2. Producing a complete implementation plan as a task DAG, following the schema in your system prompt.
3. Writing the plan to the run ledger and `session.plan()`.
4. If `require-initial-plan-approval` is true (default), present the plan summary to the user and wait for "approve". If `full-auto` is true, proceed directly to dispatch.
5. Dispatching tasks via `smart-task` rank by rank.
6. Iterating through verification, arbitration, and meta-evaluation as needed.
7. Surfacing the final summary with `/apply` when complete.

Use a unique `plan_id` derived from the current timestamp (e.g. `plan-YYYYMMDD-HHMMSS`).
